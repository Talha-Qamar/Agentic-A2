# zari-headless

A headless Next.js storefront with incremental static regeneration, image optimisation and a Shopify checkout.

**Stack:** TS, Next, Shopify Storefront API, Tailwind CSS, Vercel

## Why
Built for a e-commerce client where a theme-based store scored 31 on mobile Lighthouse and lost shoppers on slow pages.

## Quick start
```bash
npm install && npm run dev
```

## Results in production
- mobile Lighthouse score from 31 to 94
- conversion rate up 19% month over month

## Layout
- `src/` application code
- `tests/` unit tests
