# prospect-notes

A Manifest V3 extension with a side panel, offline-first storage and sync to a Supabase backend.

**Stack:** TS, Chrome Extensions, React, Supabase

## Why
Built for a sales tech client where reps kept prospect notes in spreadsheets that never synced.

## Quick start
```bash
npm install && npm run dev
```

## Results in production
- 1,200 weekly active users after launch
- Chrome Web Store rating of 4.7

## Layout
- `src/` application code
- `tests/` unit tests
