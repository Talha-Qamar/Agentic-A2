# roshan-site

A Sanity-backed Next.js site with structured content, English/Urdu localisation and WCAG AA checks.

**Stack:** Next, Sanity, Tailwind CSS, Vercel

## Why
Built for a non-profit client where volunteers could not update a WordPress site without breaking the layout.

## Quick start
```bash
npm install && npm run dev
```

## Results in production
- content edits by non-developers went from 0 to about 30 a month
- page weight down 70%

## Layout
- `src/` application code
- `tests/` unit tests
