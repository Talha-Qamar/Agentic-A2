# SadaPay Partners: admin tools in 2025

When SadaPay Partners reached out, ops staff had database access to fix customer issues, which failed a compliance review. I spent 5 weeks on it. The heart of the solution was a React admin panel on a NestJS API with attribute-based permissions and an append-only audit trail, built with TypeScript, a modern single-page frontend, NestJS, PostgreSQL.

The part I am proudest of: direct production database access removed for 40 staff. Passed the follow-up compliance audit.
