# Case study: PulseFit

**Situation.** Class bookings ran through WhatsApp groups.
**Task.** Deliver a production-ready fix within 10 weeks for a fitness business.
**Action.** A cross-platform app with class booking, waitlists, payments and push reminders. Tooling: one app for both iOS and Android, TypeScript, Firebase, Stripe.
**Result.** 4,000 downloads in the first two months; class fill rate up 18%.
